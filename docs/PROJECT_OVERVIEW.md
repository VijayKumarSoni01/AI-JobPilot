# Project Overview - AI JobPilot

## Introduction
**AI JobPilot** is an AI-powered job application tracker, resume tailoring assistant, and interview preparation platform designed to streamline and automate the modern job search process.

## Core Features & Modules
1. **Job Application Tracker**: Centralized dashboard to track applied jobs, statuses, interviews, and recruiter contacts.
2. **AI Resume & Cover Letter Tailor**: AI-driven generation and optimization of resumes matched to specific job descriptions.
3. **Interview Prep & Question Bank**: AI-generated mock interviews and customized question practice based on resume and job postings.
4. **Analytics & Insights**: Insights on application success rates, interview conversion, and skill gaps.

## Technology Stack
- **Backend**: Java 21, Spring Boot, Spring Data JPA, Spring Security, Flyway, MySQL, Lombok, Actuator.
- **Frontend**: Planned (React / Next.js / TypeScript / Tailwind CSS).
- **Database**: MySQL 8.0+.
- **DevOps / Tooling**: Docker, Maven, Git & GitHub.
